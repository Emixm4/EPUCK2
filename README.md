## About The Project 

This project simulates an angry neighbor using an [e-puck robot](http://www.e-puck.org/). Equipped with microphones, infrared sensors, and motors, the robot is designed to exhibit the following behaviors:  

- Detect and track a noise source using TOF processing on microphone signals, followed by a PID controller for the motors.  
- Emit flashing lights while seeking, mimicking a police car.  
- Produce a sound upon obstacle detection, where the obstacle represents the door of a noisy neighbor's party.
